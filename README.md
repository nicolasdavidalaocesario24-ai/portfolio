## Héberger sur GitHub Pages
1. Ouvre ton repo sur github.com
2. "Add file" → "Upload files"
3. Glisse uniquement `index.html` à la racine
4. "Commit changes"
5. GitHub Pages se redéploie automatiquement (1-2 min)
